## 💗 Sobre a Clara Bellla

A **Clara Bellla** é uma loja criada para transformar pequenos acessórios em presentes divertidos, delicados e surpreendentes.

A proposta combina **caixinhas misteriosas, acessórios de cabelo, papelaria, chaveiros, pulseiras e presentes temáticos**, permitindo que a cliente escolha a categoria e a quantidade enquanto o modelo exato continua sendo uma surpresa.

> 🎁 **Promoção:** compras acima de **R$ 100,00** recebem um **Saquinho Misterioso Clara Bellla**.

---

## ✨ O que já funciona

- 🛍️ catálogo inicial de produtos;

## 🚀 Executar localmente

Você pode abrir o `index.html` diretamente para visualizar a interface.

Para testar corretamente recursos de **PWA** e **service worker**, use um servidor local:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## ⚖️ Produtos surpresa

A Clara Bellla não vende uma surpresa completamente indefinida.

A cliente deve saber previamente **a categoria, a quantidade de itens e as características gerais do kit**. O elemento misterioso fica restrito principalmente ao modelo, cor ou combinação recebida.

Isso torna a experiência divertida sem deixar de informar claramente o que está sendo comprado.
